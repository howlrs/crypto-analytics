# ETH・HYPE関連 LP の過熱状況

調査日: 2026-09-22 JST。対象はHyperliquidのHLPと、HyperEVM上の代表的なHYPE・ETH関連DEXプール。Ethereumメインネットや全DEXを網羅した調査ではない。注文、ウォレット接続、資金移動は行っていない。

## 結論

**LP全体が過熱しているという証拠はない。HLP本体には強い資金集中・高レバレッジ化の根拠が乏しい。一方、nestの報酬型LPは要注意、Project Xでは売買活動と手数料由来の表示利回りが活発化している。**

「先物ロングの過熱」「LPへの資金集中」「LPが引き受ける価格変動・在庫リスク」は別の評価軸。HYPEの先物Fundingが低めでも、HYPE関連LPの出来高・表示APYが高いことは矛盾しない。売り、裁定、ヘッジもLPの出来高・手数料を増やすため、買い需要の証明にはならない。

本報告の「過熱」「要注意」は定性的な整理であり、検証済みの過熱スコア、損失確率、利回り予測ではない。

## 1. HLP本体：強い過熱の根拠は薄い

HLPは、複数のマーケットメイク戦略、清算、USDC貸出等を行うプロトコル・ボールトであり、通常の2資産AMMプールとは異なる。[公式説明](https://hyperliquid.gitbook.io/hyperliquid-docs/hypercore/vaults/protocol-vaults)

| 指標 | 観測値 |
| --- | ---: |
| 全体portfolioの口座価値（AUM代理値） | 約1億8,607万ドル |
| 公式APIの表示APR | 約3.29% |
| APIのday期間損益 | +3,809ドル、期首口座価値比+0.0020% |
| APIのweek期間損益 | +108,318ドル、同+0.0579% |
| day期間の入出金残差推定 | 約−34.1万ドル |
| week期間の入出金残差推定 | 約−101.6万ドル |

day期間は正確には24時間24分、week期間は7日1時間38分。残差は `口座価値増減 − 同期間PnL増減`。同一レスポンス・同じ開始/終了時刻を使った会計上の代理値であり、実際の入出金イベントを全件照合した数字ではない。AUM変化をそのまま純流入と呼ばない。

公式に親へ紐づく7子ボールトの標準perps状態を取得した範囲では、グロス建玉約929万ドル、使用証拠金約46.5万ドル。親のperps口座価値約4,666万ドルを参照分母にすると約19.92%・1.00%。限定された口座範囲の記述値で、HLP全体の統合レバレッジや清算確率ではない。

この範囲のETHネット建玉は約1.85万ドルのショート、HYPEは約0.54万ドルのロング。規模は小さく、HLPが大きなETHロング/HYPEショートを構築している証拠にはならない。他の戦略、現物、Earn、別DEXのポジションまで統合した方向判断ではない。

**評価:** 入金殺到や高レバ化を示す強い観測はない。ただし過去の同一条件のレバレッジ分布を持たず、「平常」「安全」を統計的に証明したわけではない。

以前の4–48時間という時間軸に関しては、HLPへの新規預入には**最後の入金から4日間の出金制限**がある。短期で出金する前提の運用とは合わない。[公式ロック条件](https://hyperliquid.gitbook.io/hyperliquid-docs/hypercore/vaults/protocol-vaults)

## 2. DEX LP：プールごとの差が大きい

以下の表示APYとTVLは同じDefiLlamaプール記録を使用。TVLはドル評価額で、純入金ではない。APYは年率換算表示で、将来の確定収益でも、価格変動やインパーマネントロスを引いた実損益でもない。

| Project X WHYPE/USDC・0.05% | 1,471.7万ドル | 40.32% | −1.49% | +3.54ポイント | 高い取引回転。入金過密の証拠とは異なる |
| Project X WHYPE/UETH・0.3% | 199.3万ドル | 39.56% | +3.77% | +16.16ポイント | 手数料由来の表示利回りが上昇。資金の急集中は未確認 |

UETHはデータ上のUnit Ethereum、WHYPEはWrapped HYPE。ラップ資産・ブリッジ等のリスクはETH/HYPEの先物とは別にある。

履歴の出典: [Project X WHYPE/USDC](https://yields.llama.fi/chart/f55a970c-7fdb-4087-8c62-258287e7a6cd)、[Project X WHYPE/UETH](https://yields.llama.fi/chart/5f952da0-ffd8-4665-9314-9319e4cafaa8)、[nest WHYPE/USDC](https://yields.llama.fi/chart/afe2c8c8-2ab8-4f1b-abda-a8a12718c431)、[HyperSwap WHYPE/UETH](https://yields.llama.fi/chart/7223e3c9-85ba-424a-91be-f02dcb6f155e)。当時のレスポンスは同梱証拠で固定している。

### nest：今回もっとも注意したい場所

nest WHYPE/USDCのTVLは、取得できた約6日17時間の比較で**+48.46%**。表示APY110.73%は、集計上すべて`apyReward`欄で、`apyBase`は欠測。手数料がゼロという意味ではないが、「取引手数料だけで年率111%」とは読めない。

報酬トークンのコントラクトをDEXのNESTと照合した。同じNESTの比較的大きいNEST/WHYPEプールでは、取得時の24時間価格変化が**+79.73%**。報酬トークンの価格が上がればドル換算の報酬APYも膨らみ得るため、高い表示APYを持続可能な収入と見なすのは危険。今回の上昇を価格・発行量・TVL要因へ厳密に寄与分解したわけではない。[NEST市場データ](https://dexscreener.com/hyperevm/0x535f30f50ebda33575242c38b976e681d13db6fa)

**評価:** 報酬追随・TVL拡大による局所的な熱さはある。ただしTVL増加の全額を純入金と認定せず、報酬終了時や価格下落時の利回り低下を警戒する。

### Project X：売買は活発だが、LP資金の殺到とは限らない

DefiLlamaのWHYPE/USDC・0.05%記録では、集計24時間出来高約3,781万ドル、現時点TVLの約2.57倍。TVLは約17時間で減少しており、高い表示利回りを資金流入の過熱と同一視しない。

別に取得したDEX ScreenerのProject X USDC/WHYPEプールは、流動性約1,470万ドル、直近24時間出来高約5,403万ドル、比率約3.68倍。直近1時間出来高約411万ドルは、それ以前5時間の1時間平均の約1.27倍。両サービスの集計時刻・期間・方法が異なるため、出来高の差を誤差として潰したり、片方のAPYと他方の出来高を組み合わせて予想収益を作ったりしない。[プール市場データ](https://dexscreener.com/hyperevm/0x6c9a33e3b592c0d65b3ba59355d5be0d38259285)

WHYPE/UETHのDefiLlama表示APYは約17時間で23.40%→39.56%。TVL増加は+3.77%にとどまる。報酬欄ではなくbase欄の増加であり、手数料獲得機会の増加を示唆するが、実際のポジションが範囲内か、裁定損失・価格乖離を上回るかは別問題。

## 3. ETH/HYPEペア取引の仮説について

**ETH・HYPEの組み合わせで現物スワップが行われていることは確認できた。取引所間のロング/ショート・ペアトレードまでは確認できない。**

Project XのUETH/WHYPEプール（約01:31取得）では、流動性約198.1万ドル、24時間出来高約103.3万ドル、直近1時間出来高約9.54万ドル。API上のUETH側buy/sell件数は**83件/3件**で買い側へ偏っている。ただし件数は取引金額でも純流入額でもなく、同じ主体の反復売買やルーター・裁定も含み得る。[UETH/WHYPE市場データ](https://dexscreener.com/hyperevm/0xaf80230eb13222db743c21762f65a046bb5f5437)

先ほどの「ETH優位・HYPE劣位」という仮説に整合する補助材料にはなる。しかし、取引主体の属性、別取引所の反対ポジション、HYPE売却代金の最終行き先は追えていない。現物LPを保有すること自体も、ETHロング/HYPEショートと同義ではない。

## 4. LP参加を考える場合の別のリスク

- 集中流動性では、**価格範囲を外れると手数料を稼げなくなる**。総TVLだけで現在価格付近の有効な流動性やスリッページ耐性は分からない。[HyperSwap公式説明](https://docs.hyperswap.exchange/docs/amm/protocol-concepts/liquidity-pool/concentrated-liquidity-position)
- ETHとHYPEの相対価格が一方向へ動けば、LPの資産構成が変わり、単純保有との比較で不利になる場合がある。高い年率表示だけで相殺できるとは限らない。
- 報酬トークン依存のAPY、スマートコントラクト、ラップ資産、ブリッジ、出金条件は別々に確認が必要。

**取引の強弱判断への含意:** LPの活発化を理由にHYPEのロング評価を引き上げない。今回得られたのは「局所的に取引・報酬が熱い」という証拠であり、「HYPE買い需要が戻った」「ETH/HYPE裁定が確実に収益を生む」という証拠ではない。

## 証拠・再現性・未確認事項

- `data.json`: 数値、期間、選択プール、出典URL、取得時刻、SHA-256、制約。
- `evidence.zip`: 公開レスポンス32件、各取得記録、計算スクリプト、調査メモ。ドキュメントの`.md` URL一件は404で、通常ページから取得した記録も保持。
- 公式HLPアドレスは[公式Info API資料](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint)の例示と実際のvault名を照合。子7件は公式親子関係から取得し、個人ウォレットを推定したものではない。
- DEXのTVL変化を純入金と区別した。価格変動と入出金が混ざる点は[DefiLlamaの定義](https://docs.llama.fi/analysts/data-definitions)にも明記されている。
- 時系列はタイムスタンプで照合。Project Xの約175時間の欠測区間を検知し、7日比較を欠測扱いにした。約17時間の変化を24時間と表記していない。
- HLPの子perps集計は全体AUM・親口座と単純加算しない。別DEXの全ポジション、全LPの有効レンジ、LP参加者別の実現損益、ミント/バーン純入金、清算・ヘッジ主体の完全な対応付けは未取得。
- 通信はDNSとIPv4 TCPを検証済みExpressVPNインターフェースに拘束したローカルプロキシ経由のみ。直接通信へのフォールバックなし。
- `surrealdb-recall`の継続確認手順に従い、直前の先物過熱分析とは評価対象を分離した。既存コード・過去レポートは変更していない。
