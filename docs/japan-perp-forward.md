# 日本株 perp キャリーと空売り比率の将来検証（事前登録 2026-10-30 UTC）

`docs/jquants-standard.md` の推奨「SOFTBANK・KIOXIA の funding キャリーを 2026-11 から事前登録して追跡する」と
「空売り比率（S3）の将来検証」を実装し、**2026-11-02 の東証大引けより前に**規則を固定した。
売買推奨ではなく、ペーパー追跡である。BTC/ETH の封印済み registry（`docs/prospective-validation.md`）とは独立している。

## 2. 設計入力: 決算ジャンプと perp 売りのレバレッジ（`backtests/japan_earnings_risk.py`）

perp の売りは Hyperliquid の隔離証拠金、ヘッジの現物は日本の証券会社にあるので、日次の証拠金確認と確認の間のジャンプで
perp 側だけが清算されうる。決算短信サマリーの開示日時から反応セッション（大引け前の開示は当日、後なら翌営業日。
大引けは 2024-11-01 まで15:00、2024-11-05 から15:30）を決め、前日終値に対する高値の上昇幅を測った。
xyz では、東証終値時点（15:30 JST）の間の perp の1時間足高値を使う（夜間の PTS 連動の反応も入る）。

| 銘柄 | 決算（定期開示） | 決算日の平均絶対変化 / それ以外の日 | 決算日の最大上昇（東証高値） | 全日の最大上昇（東証） | xyz の終値間最大上昇 | 上位10の上昇日に占める決算日 |
|---|---:|---:|---:|---:|---:|---:|
| SOFTBANK（9984） | 42回（2016-10〜） | 5.0% / 2.0% | +17.7%（2019-02-07） | +21.0%（2020-03-24） | +18.7% | 2/10 |
| KIOXIA（285A） | 8回（2024-12〜） | 9.2% / 4.7% | +19.2%（2025-02-17） | +24.2%（2025-04-08） | +32.2% | 1/10 |

- 決算日は普段の2倍強動くが、最大級の上昇はマクロ急変日（2020-03、2025-04 の関税ショック後の反発）に多い。
  決算日だけ証拠金を積み増す規則より、**常時のレバレッジを最大級のジャンプに合わせる**ほうが効く。
- 規則（結果を見る前に決めた）: 1.5 / 2 / 3 / 4倍のうち、清算余裕（1/L − 0.05）が最悪上昇の1.25倍以上ある最大の倍率。
  SOFTBANK は 1.25 × 21.0% = 26.2% ≤ 28.3% で **3倍**、KIOXIA は 1.25 × 32.2% = 40.2% ≤ 45% で **2倍**。
  前回の目安（KIOXIA 2倍、SOFTBANK 3倍）と同じになった。
- 東証の日次は値幅制限で上限が切られるが、perp には制限がない。KIOXIA の xyz 上の +32.2% は東証の動きを上回った
  （前回 `docs/jquants-standard.md` の 2026-07-31 の例）。
- 直近の決算: KIOXIA は 2026-10-30 18:45 JST に2Q を開示し、xyz では同夜に約 −10%（perp 売り側に有利）。
  この開示は J-Quants の日次 bulk（18:02 JST 生成）に入っておらず、次の更新で入る。追跡の開始前なので評価には入らない。

## 3. H1: 日本株 perp の funding キャリー（主仮説）

**問い**: 東証の現物を持って xyz の perp を売ると、受け取る funding（レバレッジをかけたロングが払う）は、費用を引いても
BTC/ETH の funding capture（年率 8〜10%）を上回るか。清算なしで1年続くか。

| 項目 | 固定した内容 |
|---|---|
| 銘柄とレバ | `xyz:SOFTBANK`（9984）3倍、`xyz:KIOXIA`（285A）2倍。JP225 は funding が年率約4%で前回不合格のため除外 |
| 期間 | 2026-11-02 の大引け（15:30 JST）に建て、2027-10-29 の大引けまで（約243営業日） |
| 評価 | 毎営業日 15:30 JST。perp は 06:30 UTC 開始の15分足の始値（なければ 06:00 の1時間足終値）、公正価格は東証の未調整終値 ÷ `xyz:JPY`。日次損益（名目1あたり）= −Δ乖離 + 受取 funding（`hl_japan_carry.daily_panel` と同じ） |
| 資本 | 名目1あたり 1（東証の現物を現金で買う）+ 1/L（perp の隔離証拠金）。銘柄間は資本均等、ある日の損益は測れた銘柄の平均 |
| 費用（片道） | perp 0.9bp + 1bp、東証 5bp、円転 5bp。建てと手仕舞いで1往復、東証の分割日（`AdjFactor` ≠ 1）と清算ごとに perp の1往復 |
| 清算 | 前日終値から次の終値までの15分足（なければ1時間足）高値の上昇が 1/L − 0.05 以上なら清算とみなす。その日は証拠金を失う（損益 = 現物の USD リターン − 1/L）とし、終値で建て直す |
| 判定（2027-10-29 の評価後） | (a) 費用控除後の資本あたり年率 ≥ 8%、(b) 日次の資本あたり損益の平均 > 0 の片側 p < 0.05（Newey–West、ラグ5日）、(c) 清算0回、(d) 各銘柄で損益を測れた日が90%以上 |
| 結論の文言 | すべて満たせば `confirmed`。(d) 不足は `insufficient_data`、(c) 違反は `rejected_for_risk`、それ以外は `not_confirmed` |

- 途中で成功判定による打ち切りはしない。累積損益・受取 funding・最大上昇と清算余裕は毎回表示する（ペーパー建玉の管理に要る）が、
  p 値と判定は最終日までは空欄。
- 副次（記述のみ、合否なし）: 銘柄別の結果と、「直近10営業日の funding 合計が負になった終値で手仕舞い、0以上に戻ったら建て直す
  （切り替えごとに片道費用）」版。
- 新しい日本株 perp が xyz に上場しても H1 には入れない（追うなら別途登録する）。
- 含めないもの: 現物と証拠金の資金コスト、信用取引の金利、税、HIP-3 デプロイヤーのリスク、証拠金の移動にかかる時間。
- 参考（登録前に計算した過去区間で、判定には使わない）: 同じ台帳で 2026-08-31〜10-30 を評価すると、費用控除後の資本あたり
  年率 8.2%、t = 1.1、清算なし。SOFTBANK の終値間最大上昇は +18.7%（3倍の余裕 28.3% の内側）。

## 4. H2: 空売り比率は日経225の翌週を予測するか（Standard 固有データの将来検証）

前回（2017-08〜2026-07 の465週）は S3 だけが事前の向きで片側 p = 0.021 だったが、BH 補正後 q = 0.063 で、効果は 2022 年以降に偏った。
これを、まだ誰も見ていない将来データで確かめる。

| 項目 | 固定した内容 |
|---|---|
| シグナル | `japan_positioning.py` の S3 と同じ（33業種合計の空売り代金比率、判断日前5営業日の平均、直前52判断週で z 化）。設定値は registry に保存 |
| 判断と目的変数 | 各 ISO 週の最後の東証営業日の大引け。翌判断日までの日経225の対数リターン |
| 期間 | 判断日 2026-11-06〜2028-10-27（約104週） |
| 判定 | 傾きの片側 p < 0.05（Newey–West、ラグ4、単一仮説）かつ、週次ルール（符号 × clip(z, −1, 1)、回転1単位 3bp）の平均損益 > 0。有効な週が90未満なら `insufficient_data` |
| 開示 | 最終評価まで、件数と最新のシグナル（z とポジション）だけを出す。成績は出さない |
| 空白期間 | 2026-08-07〜10-30 の判断（研究境界の後、登録の前）は登録後に初めて計算し、記述として別に表示する。本検定には合算しない |

**検出力**: 104週では、週次の相関 0.2 で約6割、0.1 で約2.5割。帰無でも小さな効果は否定できない。一方、効果があったとしても
週次の指数タイミングで Sharpe 2 には届かない見込みなので、本プロジェクトでの位置づけは「Standard 固有データの唯一の残り候補の決着」である。

- xyz の15分足は API が直近約52日分しか返さない。間隔が空くと終値時点の価格が1時間足の代用（30分遅れ）になり、清算判定も
  1時間足になる。
- `status` は registry の内容とサイドカーの SHA-256、スクリプト内の規則との一致を確かめ、合わなければ止まる。登録時から変わった
  追跡対象コード（`hl_japan_carry.py`・`japan_positioning.py`・`japan_forward.py`・`japan_earnings_risk.py`）は
  `code_changed_since_registration` に出る。変更する場合は、影響するデータを見る前に下の変更ログへ書く。書かずに変えた結果は確認的に扱わない。
- 出力には J-Quants 由来の日次・週次の値が入るので、リポジトリには置かない（コードで拒否）。

## 6. 確認して使わなかったもの

- **信用規制と funding**: 東証の信用規制（日々公表銘柄・増担保）で日本の信用買いが締め出されると、レバレッジ需要が xyz に移って
  funding が上がる、という経路を考えた。日々公表信用取引残高（2016-10〜2026-10-30 公表分）を見ると、9984 も 285A も一度も対象になっておらず、
  検証できる事例がない。
- **空売り残高報告**（0.5%以上の報告、2016-10〜2026-10）: KIOXIA に141件（中央値 0.67%、最大 6.6%、証券会社の報告が大半）、SoftBank に14件（最大 0.81%、最後は 2025-07）。銘柄別の売り圧力として使う設計は立てていない。
- **`xyz:EWJ`**: 日本株 ETF の perp だが、参照は米国上場の EWJ で、東証の終値では評価できない。
- xyz の日本関連銘柄は 2026-10-30 時点でも JP225・KIOXIA・SOFTBANK・JPY の4つで、前回から増えていない。
